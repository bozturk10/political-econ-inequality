# Brazil–Mexico figures for the agreed program windows

**Outcome windows:** Mexico 1997–2014; Brazil 2003–2014. **Common mechanism window:** 2003–2014, when both national CCTs operated. The supplied PPTX has not been edited.

## 01 SWIID inequality endpoints

`01_swiid_inequality_program_windows.png` and `.svg` reproduce the rounded start and end values in the table embedded on slide 4 of the supplied presentation. The arrows run from the earlier year to 2014 on a chronological x-axis and slope downward as Gini falls. The source label there identifies SWIID 8.0. This figure intentionally shows endpoints only; it does not claim to recreate annual observations. The unequal window lengths matter. These are descriptive changes in market and disposable income inequality, not causal estimates of CCT effects.

The historical SWIID 8.0 archive could not be downloaded during this work because the browser download approval was declined. Its raw figures therefore could not be checked independently against the presentation. If the group needs an annual redraw, provide the `swiid8_0_summary.csv` used for slide 4 or an approved current SWIID export. Newer SWIID versions may change the estimates.

## 02 ILO real minimum wage

`02_real_minimum_wage_overlap_2003_2014.png` and `.svg` use ILO's national real minimum wage index for the shared 2003–2014 CCT period. ILO publishes this index with 2000 = 100. The figure rebases each country's series to 2003 = 100 by calculating `100 × ILO index in year t / ILO index in 2003`. Brazil therefore ends at 173.4 (+73.4%) and Mexico at 100.5 (+0.5%). Original ILO values: Brazil 117.4 to 203.6, Mexico 101.2 to 101.7. Sources: [ILO Labour Overview 2013](https://www.ilo.org/sites/default/files/wcmsp5/groups/public/%40americas/%40ro-lima/documents/publication/wcms_242634.pdf) and [ILO Labour Overview 2015, Table 10](https://www.ilo.org/sites/default/files/wcmsp5/groups/public/%40americas/%40ro-lima/documents/publication/wcms_450098.pdf). The index supports comparison of percentage changes within each country, not wage purchasing-power levels across countries.

## Why the previous figures were not reused

The earlier 2008–2014 WDI Gini/bottom-20 figure addresses a different, now superseded puzzle. It also crosses a Brazilian household-survey change, so its endpoint changes should not be treated as a clean trend. WHO's available UHC observations for 2000, 2005, 2010 and 2015 do not provide the requested 1997/2003–2014 endpoints, and the index does not identify health-system segmentation. The out-of-pocket expenditure series is still provisional because the historical values came from a third-party mirror. Neither health figure is in the updated presentation package.
